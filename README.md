## 👋 About me

- 🏭 **IT Developer at [Tala Living](https://github.com/it-tala)** — a furniture manufacturer. I build the internal **Manufacturing OS**: BOM & costing, production tracking, and operations tooling used daily on the factory floor.
- 🤖 Currently focused on **John Lau**, an LLM-powered operations assistant that answers questions straight from production data (tool-calling, SQL routing, human-confirmed writes).
- 📊 I like the unglamorous parts: data models, migrations, spreadsheets that sync with real databases, and automations that remove manual re-typing.
- 🌱 Learning more about team Git workflows, PR reviews, and shipping safely to production.

## 🚀 What I'm building

| Project | What it does | Stack |
|---|---|---|
| **Manufacturing OS** | Internal ERP-lite for a furniture factory: BOM & costing engine, rate snapshots, production ops | Next.js · Supabase · Postgres · Cloudflare Workers |
| **John Lau** | Ops assistant that turns natural-language questions into safe SQL & tool calls, with confirm-before-write | TypeScript · LLM tool-calling · Postgres |
| **BOM Sheet Sync** | Google Sheets ↔ Supabase bridge so operators can input BOMs where they're comfortable, with locked rate snapshots | Apps Script · REST · Postgres |
| **WhatsApp Ops Bots** | Group listeners & digest bots that surface decisions and blockers to the right people | Node.js · Baileys · Hermes Agent |
